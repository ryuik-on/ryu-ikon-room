# Visual direction — discussion draft

これは今後Claude・人間と検討するための前提であり、決定済みデザインではありません。

## 確認済みの方向

- 写真、映像、余白を主役にする
- 奏者と観客の間に生まれる空間を表現する
- 派手さだけでなく、緊張感や人の熱を感じる
- 学園祭の告知サイトに見せない
- テンプレート的なロックサイトに見せない
- モバイルを最優先する
- 説明より先に体験を置く

## 避けるもの

- 旧サイトの見た目の踏襲
- ネオン調
- 音符や波形の装飾
- 大量の英語コピー
- 黒背景に巨大文字を置くだけの構成
- 過剰なスクロールアニメーション
- 不要なグラデーション
- テンプレート的なバンドサイト
- 装飾を目的とした演出

## 今後の検討軸（提案であり未決定）

- 写真の選定は「格好よさ」だけでなく、奏者と観客の距離、迷い、集中、熱が写っているかで評価する
- 動きは意味のある場面に限定し、静止状態でも内容が成立することを先に確認する
- 余白は装飾ではなく、視線と感情の切り替えに使う
- 色と書体は素材の色・主催者の既存ブランド・可読性を確認してから決定する
- Heroは最初の5秒で公演名と日程を読めることを優先し、演出で遅らせない

## 2026-07-24: GPT版デザインとの折衷を採用

主催者がChatGPTに作らせたROOM LP（Next.js製、`ROOM-source-for-Claude.zip`）のデザインシステムを気に入り、折衷案として採用（プラン: `~/.claude/plans/velvet-snacking-fairy.md`参照）。GPT版のレイアウト・タイポグラフィ・モーションをAstroへ移植し、内容は確定情報・確定コピーを維持。写真3枚のセクションは残し、朱色アクセントを採用、コピーは確定コピー＋GPT創作コピーの両方を使用（GPT分の採用は主催者のプラン承認をもって決定済み）。

- **カラーパレット（確定）**：墨黒`#080808`（背景）、温白`#f1efe9`（反転セクション背景・本文の主色）、灰`#aaa7a0`（副次テキスト）、朱`#a94738`（小面積アクセントのみ：process/invitationの点、フォーカスリング、skip-link）。以前「金色はダサい」でモノクロ化した経緯があるが、今回は主催者が明示的に朱色を指定
- **書体（確定）**：欧文はArchivo（可変フォント、幅62–125%・太さ100–900の全軸）をセルフホスト（`public/fonts/archivo-variable-latin.woff2`、SIL OFLライセンス）。「ROOM」の巨大見出しなどはfont-stretchで実際にコンデンス化する。日本語はシステムフォントのままフォールバック
- **動き（確定、Phase 10を待たず先行導入）**：Heroはスクロール連動で白い帯（部屋の扉）が開く演出（`--room-open` CSS変数をスクロール位置から計算）。各セクションはIntersectionObserverでフェードイン。いずれも`prefers-reduced-motion: reduce`で即座に最終状態に固定し、アニメーションを無効化。「過剰なスクロール演出を避ける」方針とは緊張関係があるが、reduced-motion対応と抑制的な動きの量を条件に主催者が採用を決定
- **ロゴの扱い**：Heroの固定ヘッダーはロゴ画像でなく「ROOM」のテキストブランド＋`mix-blend-mode: difference`（暗背景・明背景どちらでも自動で色反転）。Ryuik-onスカルロゴ画像は現状未使用（footer等での再導入は今後検討）
